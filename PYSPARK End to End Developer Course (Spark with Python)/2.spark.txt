What is RDD?-Resilient Distributed Datasets 
it is low level api spark is built on it 
it is a low-level data strucute which spark uses to distribute the data btwn tasks 
while data is being processed 

Features-
1.Resilient
2.Distributed
3.Lazy Evaluation-
each transformation is lazy operation.evaluation is not started until an action is triggered
4.Immutablity 
5.In-memory computation
