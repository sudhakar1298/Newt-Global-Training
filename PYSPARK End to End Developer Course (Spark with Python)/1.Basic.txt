HDFS-
Hadoop Distributed file system 
it is specially designed file system for storing large amt of data we can
scale it verticaly and horizontally

Big data Challanges-
Stroage and processing

for stroage use hdfs 
for processing use map reduce and spark

HDPS components -
it follws master-slave architecture 
it has one name node and many data node 

Namenode-
all the meta data of data node is stored in data node 

in namenode there are two files editlog and fsimage
editlog keeps recent changes made on hdfs 
fsimage keeps track of every change made on hdfs 

secondary namenode-
it works as namenode if the first namenode fails 	 
it copies the fsimage and editlog periodically 

DataNode-
stores the data in blocks
performs rw operations as per client request 

HDFS Data Blocks-
hdfs split big files in small split files called data blocks

Rack Awareness-
rack is a collection of 30-40 nodes 
it is a concept that helps to decide where the copy of the data node 
to be stored 

3 copies of a block cannot be stored in a single rack but
2 copies can be 

HDFS Reading mechanism-
client opens dfs and sends a rpc call to name node and name node
sends the meta data of data and that is sent back to client and 
client sends that to the fsdatainputstream which collects the
data and gives it to client 
at last client closes the connection
