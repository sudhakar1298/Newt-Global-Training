Merge--
MERGE INTO TargetTable AS T
USING SourceTable AS S
ON T.ID = S.ID
WHEN MATCHED THEN
    UPDATE SET T.Name = S.Name, T.Price = S.Price
WHEN NOT MATCHED THEN
    INSERT (ID, Name, Price)
    VALUES (S.ID, S.Name, S.Price)
WHEN NOT MATCHED BY SOURCE THEN
    DELETE; -- Optional: cleans up target rows not in source

LOB---- we cant use group by order by or primary key 
LOBs (Large Objects) are specialized SQL data types designed to store massive
amounts of unstructured or semi-structured data—like images, videos, large 
PDF documents,  or long XML/JSON files—that exceed the standard 4,000-byte 
limit of regular data types like VARCHAR2 or RAW.

BLOB (Binary Large Object): Stores unstructured binary data (e.g., images, audio, video).
It is treated as a stream of bytes without character set semantics. 

CLOB (Character Large Object): Stores large blocks of character data using the database's 
default character set (e.g., long text documents, HTML). 

NCLOB (National Character Large Object): Similar to CLOB but uses the National Character Set'
(typically Unicode) to support multi-byte characters for international text. 

BFILE (Binary File): An "external" LOB that stores a pointer (locator) in the database while
the actual file remains on the server's operating system. These are read-only and do not
support database transactions like COMMIT or ROLLBACK.
